### 目标与非目标
**目标**：certAlg 可选参数+certStoreInfo+按算法过滤+向后兼容。
**非目标**：不新增 IPC 消息码；不升级 D1 算法判定（沿用 SM2 OID）；NDK/ANI/CJ 同步后续。

### 数据结构约定
`CertStoreInfo { certStoreVersion: string; smcertStoreVersion: string }`；`CmCertAlgorithm { ALL=0, INTERNATIONAL=1, SM=2 }`。跨仓语义：可选参数缺省=ALL，向后兼容。
